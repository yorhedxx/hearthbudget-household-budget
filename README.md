HearthBudget is a working household budget site for one Jakarta family (the Pramudyas, November 2026) in real Rupiah: a dashboard with a next-14-days bills strip and a Payday Forecast that projects the balance to the next payday, an interactive Budget Plan whose sliders recalculate the plan live, a searchable Transactions ledger, and Bills & Goals with savings rings, a mortgage payoff chart and a "Can We Afford It?" sinking-fund calculator — all computed from one data source, with no framework and no network requests.

## Run it

```sh
node serve.ts
```
